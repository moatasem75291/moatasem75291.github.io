Case 04 / Research prototype

Modern Data Platform & Lakehouse

A data platform prototype exploring batch ingestion, CDC and analytics-ready data through the Bronze, Silver and Gold layers.

PostgreSQLApache AirflowDebeziumApache KafkaChange Data CapturedbtSeaweedFSObject StorageData LakehouseData WarehousingMedallion ArchitectureData ValidationData PipelinesApache Iceberg concepts

The problem

A platform must ingest source changes, support repeatable transforms and deliver trustworthy analytics without operational complexity that the workload does not justify.

My responsibilities

Prototyped PostgreSQL batch and CDC ingestion, Airflow orchestration, dbt transformations, and data validation. Compared warehouse and lakehouse architecture choices.

Read all architecture steps
  1. PostgreSQL — Start with a source database and a defined snapshot boundary.
  2. Batch & CDC — Orchestrate batches with Airflow and capture database changes through Debezium and Kafka.
  3. Bronze — Retain source records and change events in a raw layer.
  4. Silver — Clean, reconcile and validate source data through transformations.
  5. Gold — Expose modeled facts and metrics for consumption.

Engineering decisions

Challenge

Keep snapshots and CDC events aligned. Check transformation outputs and failure recovery through the batch and streaming paths.

Approach

Preserve raw data before applying contracts and business models. Compare warehouse and lakehouse options with the same validation questions.

Evaluation & outcomes

Exercised pipeline stages and dbt checks on project data. Investigated configuration and orchestration errors during testing.

Implemented batch and CDC pipeline prototypes using PostgreSQL, Airflow, Kafka and Debezium, with dbt models and S3-compatible SeaweedFS storage. Apache Iceberg catalog choices were researched.

Lessons & next steps

The storage format, orchestration and consumption layers have different responsibilities. Model them separately when comparing architectures.

Test replay and schema evolution, and compare an Iceberg-backed path against the warehouse baseline.
