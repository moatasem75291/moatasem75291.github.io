Case 03 / Applied system

Electronic Know Your Customer Platform

A modular verification workflow for identity documents, face matching and liveness, with asynchronous execution and observability.

PythonFastAPIReactNext.jsRabbitMQRedisMinIOOAuth2JWTPrometheusGrafanaComputer VisionOCRFace Matching and Liveness DetectionAsynchronous ProcessingObservability

The problem

A verification flow spans long-running processing, sensitive submissions and a case review interface, so failure and completion must be visible across services.

My responsibilities

Implemented session and customer validation, face cropping and object storage integration, configurable workflows and interfaces for capture and review. Instrumented service dependencies and built operational dashboards.

System architecture

Select a stage to inspect the data flow. The diagram uses a simplified public view.

Submission

An authenticated session submits identity images and capture metadata.

Read all architecture steps
  1. Submission — An authenticated session submits identity images and capture metadata.
  2. OCR — Extract and validate identity document fields.
  3. Face match — Compare the document portrait with face capture.
  4. Liveness — Evaluate the live capture and return verification signals.
  5. Review — Record the outcome and expose stage-level jobs and metrics for authorized operators.

Engineering decisions

Challenge

Maintain a traceable job across APIs and processing services. Give operators diagnostic context while masking sensitive values.

Approach

Represent verification as a job with queryable state. Use queue boundaries for slow work and attach correlation context to service logs and metrics.

Evaluation & outcomes

Inspect session states, processing failures and dependency measurements in operational dashboards. Public biometric accuracy figures are unavailable.

Added Prometheus instrumentation across HTTP, database, Redis, gRPC, object storage and queues, with Grafana dashboards and correlated audit logs.

Lessons & next steps

A stage-level status map is as important to operations as the final verification result.

Extend consistency checks for retries and validate accessibility across capture and review screens.
