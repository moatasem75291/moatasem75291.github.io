Case 05 / Experiment collection

AI Research & Experimental Systems

Experiments with graph extraction, Arabic NLP, embedding retrieval and local model serving.

The problem

Model quality, hardware limits and downstream use vary enough to require small controlled experiments.

My responsibilities

Prototyped multilingual entity and relation extraction, entity resolution and Neo4j graph ingestion. Compared multilingual embeddings and reranking. Tested quantized models behind a local inference API.

  1. Corpus — Choose bilingual examples and establish evaluation labels.
  2. Extract — Identify entities and relations, then resolve duplicate mentions.
  3. Compare — Compare graph, retrieval and local inference configurations against a baseline.
  4. Record — Review failure examples and record limits and follow-up questions.

Engineering decisions

Challenge

Arabic text normalization, ambiguous entity links and accelerator memory can affect results in different ways.

Approach

Use a small benchmark and track individual errors before integrating a model. Keep graph personalization as an exploration until there is a clear evaluation baseline.

Evaluation & outcomes

Compared retrieval rankings and false matches, inspected entity extraction output and tried CPU fallback when GPU memory was insufficient.

Built a graph ingestion proof of concept and exercised local LLM serving and multilingual retrieval configurations.

Lessons & next steps

Configuration changes are easier to interpret when the data, candidate set and evaluation labels are frozen.

Define a reproducible personalization benchmark and expand local serving measurements across hardware.
