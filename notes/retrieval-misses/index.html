What a retrieval miss can tell you

A note on separating candidate recall, ranking and answer grounding.

When a RAG answer is wrong, start by checking for the expected evidence in the candidate set. If it is absent, inspect ingestion, OCR, chunking and the retrieval query. If it is present but ranked poorly, compare the candidate list before and after reranking.

Questions that require several documents need their own slice. A single relevant result can look encouraging in a ranking metric while leaving the question unanswerable. Track full evidence coverage alongside the rank of the first relevant passage.

Then assess whether the answer uses the passages it retrieved. The next experiment should focus on the stage where evidence disappeared.
