# The Intelligence Architect

The composition starts with a large editorial title beside the system map. The map is a navigation device. Five connected domains lead to project evidence. Dense technical content sits behind clear summaries and disclosures.

- **Visual system** — graphite, warm off-white, cyan domain markers, restrained violet and amber. A ruled grid and terse monospaced metadata recall architecture drawings. The light theme uses paper tones and darker ink accents. Text and controls keep a consistent reading rhythm across sections.
- **Information architecture** — introduction, case studies, expertise, engineering approach, career, lab, reading and notes, contact. Individual case studies and notes have stable links.
- **Recruiters** can scan the role, public résumé, project summaries and timeline from the landing page. **Technical leads** can follow links into project decisions, architecture steps, trade-offs and evaluation. **Collaborators** can try simulations, browse the digital garden and compose an inquiry.
- **Content model** — typed records for identity, project stages and metrics, skills, experience, books, notes and settings. Published, visible, ordered records power a static export. Drafts can live in a protected authoring service and be exported for review before a GitHub Pages build.
- **Runtime** — Next.js App Router generates Pages-compatible HTML with client interaction islands. Public hosting requires no secrets or external data. GitHub authenticates repository editors. An optional Node/SQLite service stores private drafts and accepts moderated inquiries when configured.
